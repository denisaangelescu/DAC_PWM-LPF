In this project, we demonstrated how a variable-duty-cycle PWM at a single resolution can be turned into an analog signal using a carefully configured low-pass filter. By smoothing the pulse train, the resulting waveform’s amplitude closely follows the duty cycle, peaking when duty cycle is at its maximum. We investigated time delays, performed FFT-based frequency analysis, and compared two different LPF topologies. This straightforward approach confirms that a well-tuned PWM–LPF system can serve as an effective entry-level digital-to-analog converter.
